# Cerebro Escuela MELANT

## Alcance
Biblioteca didactica para formacion tecnica: clases, guias, cartillas y material de entrenamiento.

## Objetivo operativo
Convertir conocimiento tecnico en aprendizaje aplicable para productor, tecnico y promotor.

## Estructura recomendada
1. Nivel basico: conceptos claves y practicas seguras.
2. Nivel intermedio: diagnostico y decisiones por caso.
3. Nivel avanzado: diseno de planes de manejo por unidad productiva.

## Tipos de contenido
- clases
- guias
- manuales
- presentaciones
- cartillas

## Uso dentro de MELANT IA
- Soporte explicativo cuando el usuario pide "como hacer".
- Refuerzo de fundamentos antes de una recomendacion de alto riesgo.
- Material para rutas de capacitacion por modulo.
- Manual corto para practicas regenerativas como Beauveria bassiana y evidencia fotografica.
- Manual corto para microorganismos de montana, cobertura de suelo y observacion de micelio.
