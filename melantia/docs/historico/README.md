# Histórico de MELANTIA — melant_ia

Este directorio conserva documentación y artefactos seleccionados
rescatados desde la versión legacy `melant_ia/` antes de su retiro.

## Naturaleza

Estos archivos son históricos y documentales. No forman parte del
runtime actual de MELANTIA y no deben importarse ni ejecutarse como
configuración de producción.

## Proveniencia

Los archivos fueron extraídos desde el contenido versionado de
`melant_ia/` mediante Git antes de la eliminación de ese árbol legacy.

## Pagos

La documentación histórica de `docs/historico/pagos/` conserva una
configuración anterior que contemplaba PayPhone, Deuna y PeiGO.

La documentación histórica registra una comisión MELANTIA del 5%.
Esta cifra es histórica y NO representa la regla vigente.

La decisión vigente de MELANTIA es una comisión del 3% por transacción.
No modificar los archivos históricos para reflejar el 3%; conservar la
proveniencia histórica.

## Melantios

`docs/historico/melantios/` conserva documentación de la especificación
histórica de la economía Melantio y material gráfico asociado.

## Conocimiento agrícola

`docs/historico/manuales/` conserva manuales agrícolas seleccionados
como referencia de conocimiento de dominio procedente de la versión
legacy.

Otros contenidos de `knowledge_seeds/` permanecen pendientes de revisión
selectiva y no deben copiarse automáticamente.

## Regla de mantenimiento

Los documentos de este directorio sirven como referencia histórica,
proveniencia y recuperación de decisiones anteriores. Las decisiones
vigentes deben documentarse en la arquitectura y documentación activa
de MELANTIA, no modificando estos archivos históricos.
